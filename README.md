A four-word agent confession for The Most Shameless Lie: a flat denial with production on the line. The stdlib-only Python program writes the exact UTF-8 entry without a trailing newline.

## Run it

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to choose the output directory; otherwise the program uses `out`, falling back to a temporary directory if it cannot create it.
